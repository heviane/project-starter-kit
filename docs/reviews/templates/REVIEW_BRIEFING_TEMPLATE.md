# 📝 Template de Briefing para Auditoria Multi-Agente (MARF)

> **Instruções:** Preencha os campos abaixo com os dados do projeto a ser avaliado. Copie e cole este prompt na íntegra para cada um dos modelos de IA consultados (ChatGPT, Claude, GitHub Copilot).

---

```markdown
# Solicitação de Análise Técnica e Parecer de Arquitetura

Olá! Gostaria de submeter o repositório/projeto abaixo para sua avaliação técnica aprofundada como especialista sênior em engenharia de software e arquitetura.

## 📌 Contexto do Projeto
- **Nome do Projeto / Repositório:** `[ORGANIZACAO_OU_USUARIO]/[NOME_DO_PROJETO]`
- **URL Pública:** `https://github.com/[ORGANIZACAO_OU_USUARIO]/[NOME_DO_PROJETO]`
- **Propósito Principal:** `[DESCRICAO_DO_PROJETO]`
- **Stack Tecnológica:** `[TECNOLOGIAS_UTILIZADAS]`
- **Branch / Commit Analisado:** `main` (`[HASH_DO_COMMIT]`)

## 🎯 Escopo da Avaliação
Por favor, avalie os seguintes aspectos em ordem de prioridade:
1. **Segurança e Privacidade:** Existem riscos de exposição de credenciais, certificados, segredos ou dados sensíveis?
2. **Arquitetura & Design de Código:** Separação de responsabilidades, acoplamento, robustez e manutenibilidade.
3. **Governança & Docs-as-Code:** Clareza do README, especificações funcionais (SDD), decisões arquiteturais (ADRs) e contratos operacionais.
4. **Qualidade & Automação:** Cobertura de testes, validação de linting e pipelines de CI/CD.
5. **Storytelling & Apresentação:** O projeto transmite autoridade técnica e senioridade para avaliadores e recrutadores?

## 📋 Formato de Resposta Esperado
Por favor, estruture seu parecer da seguinte forma:
- **Resumo Executivo & Diagnóstico Geral**
- **Pontos Fortes (Destaques Positivos)**
- **Fragilidades e Riscos Críticos (Prioridade Máxima)**
- **Oportunidades de Melhoria Recomendadas**
- **Plano de Ação Sugerido em Etapas Práticas**
```
